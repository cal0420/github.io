C4G Bot

The primary application manages community features, progression, economy, moderation, profiles, inventory systems and server tools.

Music workers

C4G Music Bot 1, 2 and 3 act as dedicated voice workers. The main bot assigns an available worker so separate voice channels can have independent queues.

Release state

The system remains in private beta. Public bot invitation links are intentionally not published.

Current priorities

  • Reliable startup and reconnect behaviour;
  • automatic worker allocation;
  • queue isolation;
  • safe server configuration;
  • monitoring and recovery.
