PRIVACY POLICY

Last updated: 29 July 2026

This policy covers C4G Bot and C4G Music Bots 1–3.

Information processed

The applications may process Discord identifiers, usernames, command inputs, music searches, queues, levels, balances, inventories, moderation records, server settings and technical logs.

Use

Information is used to operate bot features, preserve settings, manage queues, provide moderation tools, diagnose faults and prevent abuse.

Storage and deletion

Temporary information is retained only while needed. Persistent feature data may remain while a server uses the applications. Deletion requests can be sent to Cal420 on Discord with the relevant user or server ID.

Sharing and security

Personal information is not sold. Data may be processed by Discord and hosting providers required to run the bots. Reasonable safeguards are used, but absolute security cannot be guaranteed.
